# 문자열 덧셈 계산기

---
## 기능 목록

- [x] 구분자와 양수를 포함하는 문자열을 입력받는다.
  - 커스텀 구분자 헤더 접두사(`//`)가 있다면?
  - [x] 헤더와 표현식 분리하기
    - [x] ⚠️ 헤더 접미사가 없는 경우 예외 발생
    - [x] 헤더에서 커스텀 구분자 추출하기
      - [x] ⚠️ 정해진 포맷이 아니라면 예외 발생
      - [x] ⚠️ 기본 구분자와 중복된다면 예외 발생
    - [x] 표현식에서 피연산자 추출하기
      - [x] 기본 구분자(`,`, `:`) + 커스텀 구분자를 기준으로 문자열 분리
        - [x] ⚠️ 빈 토큰 발생 시 예외 발생 (예: "1,,3", "1,")
        - [x] ⚠️ 양수가 아닌 수 입력 시 예외 발생
        - [x] ⚠️ 커스텀 구분자와 기본 구분자(`,`, `:`)를 제외한 문자 입력시 예외 발생
- [x] 합계 출력하기
  - [x] 피연산자들의 합계 계산하기

## 고민거리
* InputSplitter의 from에서 분기와 분기에 따른 객체 생성을 모두 담당하고 있다.
  - from에서는 입력 값에 따른 분기만을 담당할 수 있도록 메서드를 추출하자.


* inputText.substring(0, headerSuffixIndex + 2) 같은 구문은 그 자체로 의미를 파악하기 힘들다
  - 메서드로 추출하여 의도를 들어내자.

## 실행 결과 예시

```
덧셈할 문자열을 입력해 주세요. 
1,2:3
결과 : 6
```

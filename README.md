# 문자열 덧셈 계산기

---
## 기능 목록

- [ ] 구분자와 양수를 포함하는 문자열을 입력받는다.
  - 커스텀 구분자 헤더 접두사(`//`)가 있다면?
  - [ ] 헤더와 표현식 분리하기
    - [x] 헤더에서 커스텀 구분자 추출하기
      - [x] ⚠️ 정해진 포맷이 아니라면 예외 발생
      - [x] ⚠️ 기본 구분자와 중복된다면 예외 발생
    - [ ] 표현식에서 피연산자 추출하기
      - [ ] 기본 구분자(`,`, `:`) + 커스텀 구분자를 기준으로 문자열 분리
        - [ ] ⚠️ 빈 토큰 발생 시 예외 발생 (예: "1,,3", "1,")
        - [ ] ⚠️ `0` 입력시 예외 발생(예: "0,1")
        - [ ] ⚠️ 음수 입력 시 예외 발생
        - [ ] ⚠️ 커스텀 구분자와 기본 구분자(`,`, `:`)를 제외한 문자 입력시 예외 발생
- [ ] 합계 출력 기능
  - [ ] 분리된 숫자들의 합 출력

## 고민거리
* 커스텀 구분자에 대한 처리를 CustomDelimiter가 가지도록 했다.
  - 커스텀 구분자 관련 로직의 응집도가 높아짐

## 실행 결과 예시

```java
덧셈할 문자열을 입력해 주세요.
        1,2:3
결과 : 6
```
